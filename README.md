# TripleHelix website

Static site, no build step. Pages: `index.html` (home), `services.html` (what we do), `challenges.html` (Helix Challenges). English/Azerbaijani via `assets/i18n-az.js`.

## Deploy (Vercel, repo ventmap/triplehelix-website, branch main)
1. Delete the old files in the repo root.
2. Upload everything in this folder, including the whole `assets` folder (drag the folder onto GitHub's upload page).
3. Commit to `main`; Vercel deploys automatically.

## Before announcing
- Open the mailbox info@triplehelix.az (forms and footer use it).
- Have a native speaker check the Azerbaijani text (edit `assets/i18n-az.js`).
- Challenge dates are planned, not fixed; fees are "being finalised".
- Replace the text GTW badge on the home page with the GTW logo when available.
